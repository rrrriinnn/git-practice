-- matplotlib.py 설명 --

[ 개요 ]
NumPy로 몸무게 40~90kg 범위의 실수 100개와 키 140~199cm의 정수 100개를 만든 후, 여러 가지 계산 / 그래프를 만들어보는 코드이다.

[ BMI 계산 ]
키를 cm에서 m로 바꾼 다음 몸무게 / 키의 제곱으로 BMI를 계산한다.
코드에서는 저체중(18.5 미만), 정상(18.5~24.9), 과체중(25.0~29.9), 비만(30.0 이상)으로 나눠 인원수를 센다.

[ 그래프 ]
막대그래프: BMI 구간별 인원수
히스토그램: BMI 값의 분포를 6개 구간으로 표시
원그래프: 각 분류의 비율을 소수점 둘째 자리까지 표시
산점도: 키를 x축, 몸무게를 y축에 놓고 관계 확인


-- Ridge.py 설명 --

[ 개요 ]
월드컵 관련 국가별 득점 수를 예측하기 위해 Ridge 회귀를 사용한 코드다.
master_reg.csv를 읽고 국가별 실제 득점과 예측 득점을 비교한다.
원본 CSV는 이번 저장소에 포함해두지 않아 세부 입력 변수나 데이터 출처는 여기서 확인할 수 없다.

[ 데이터 나누기 ]
team, total_qual_goals, log_qual_goals를 제외한 나머지 열을 입력 변수로 사용한다.
예측 대상은 log_qual_goals다.
학습용 80%, 테스트용 20%로 나누며 random_state는 42로 설정했다.

[ 학습 과정 ]
StandardScaler를 학습 데이터에 맞춘 뒤 학습 데이터와 테스트 데이터를 변환한다.
변환한 학습 데이터로 alpha=1.0인 Ridge 모델을 학습한다.
Ridge는 계수가 지나치게 커지는 것을 방지하는 회귀 모델이다.

[ 결과와 평가 ]
전체 데이터에 대한 예측 결과를 worldcup_goal_predictions.csv로 저장한다.
저장되는 열은 team, total_qual_goals, predicted_qual_goals, prediction_error다.
오차는 예측 득점에서 실제 득점을 뺀 값이고 소수점 첫째 자리까지 표시한다.
테스트 데이터에 대해서는 RMSE, MAE, R²를 계산해 출력한다.
